# FU ToDo · Mac 应用（阶段 4）

面向低精力人群的每日计划应用。左侧月历（一天一格，格子里直接显示那天的内容），右侧是所选那一天的详情页。

## 怎么跑起来

```bash
cd "Documents/低精力计划App/app"

./build.sh          # 编译 + 跑业务规则自测 + 打包出 dist/FU ToDo.app
./build.sh run      # 上面全部做完，并启动应用
./build.sh demo     # 以示例数据启动（数据写在 demo.json，不动正式数据）
./build.sh shots    # 把真实界面离屏渲染成 PNG 到 shots/（用于设计评审）
```

打包产物：`dist/FU ToDo.app`，可以直接双击运行，也可以拖进「应用程序」。

正式数据存放位置：`~/Library/Application Support/FU ToDo/data.json`。

## 本机环境的两个坑（脚本里已经绕开）

1. **没有完整 Xcode**：只有 CommandLineTools 的 Swift 工具链（Swift 6.2.3）。因此用 SwiftPM + 手动组装 `.app`，不需要装 Xcode。
2. **不允许应用进程沙箱**：SwiftPM 默认把编译包在 `sandbox-exec` 里跑，本机会报 `sandbox_apply: Operation not permitted`（同一个原因也让无头 Chrome 起不来）。所以必须加 `--disable-sandbox`，并把编译缓存与临时目录改到 `~/.cache/yrjy`（默认位置在工作区外，会被拒写）。

这两条都写在 `build.sh` 里了，直接用脚本即可。

## 界面交互一览

| 想做什么 | 怎么做 |
|---|---|
| 拖动收尾 | 落在自己身上 / 无效位置 / 空白处松手都不会改变任何东西，源卡片立即恢复原状（有`endDrag()` + 鼠标松开看门狗兜底） |
| 调整卡片顺序 | 按住一级卡片拖动：所有卡片收起成只剩标题（松手自动展开），拖到目标位置（卡片之间 / 上方 / 下方都行）：落点线标出插入位置，其它卡片让位，被拖的卡片原位置隐藏 |
| 接进一张卡片 | 把任务拖到那张卡片上（标题行以外）＝成为它的一步；拖到主线那一行的左半边＝设为今天的主线 |
| 编辑与拖动互斥 | 一开始拖，正在编辑/正在新建的内容先自动落下再进入拖动 |
| 改错字 | 点击**这一行的任意位置**（文字、缩进区、行内空白都可以）进入编辑（与新建同款高亮）：回车＝提交并继续往下写，Tab＝提交并加下级，点击任意空白＝提交结束，Esc＝放弃 |
| 连续新建 | 鼠标移到行上 → 「＋」进入新建；**回车** = 在刚创建的那条后面继续同级，**Tab** = 在它下面新建下级，**点击任意空白** = 落下并结束，`Esc` = 放弃。锚点跟着刚创建的条目走，输入框也会跟过去 |
| 查操作说明 | 顶栏「使用说明」按钮打开独立窗口（主界面不再写这些提示） |
| 换配色 | 设置 → 配色方案卡片（暖纸 / 墨蓝 / 炭墨 / 茶白），每张带小预览，当前方案有标记 |
| 设为主线 | 把任务**拖到「今日主线」栏标题**上；原主线自动降为支线 |
| 主线降为支线 | 把它**拖到「今日支线」栏标题**上（一天可以没有主线） |
| 先加支线 | 没有主线也可以先写支线，主线栏会同时提示「今天还没有主线」 |
| 调整顺序 / 层级 | 按住行右侧的 `≡` 把手拖动（整行文字也可以拖）：拖到行的**左半边**＝同级（左上半排在它前面、左下半排在它后面），拖到**右半边**＝衔接（成为它的子步骤）；拖动时三块区会画出来；拖到栏内空白处升为顶层 |
| 跨天 | 全自动：启动时、每分钟、以及窗口重新激活时检测日期变化，无需手动操作 |
| 跨天搬任务 | 把任务拖到日历上的某一天：**整棵子树**一起移过去；那天有主线就落为支线，没有主线就直接成为那天的主线（不弹问） |
| 完成 | 点左侧圆环（连带整棵子步骤），底部提示条可撤销 |
| 恢复 | 今日完成栏或已结束项目清单里的「恢复」：**只恢复这一条 + 它上面的任务链**，子步骤与上级其他分支不动；右键可以选「恢复这条及其子步骤」 |
| 未完成项目清单 | 顶部入口：只列**一级任务**且**今天之前**的，按日期倒序，每条可「跳转」（跳到那天并高亮）、「结束」或「重新执行」（重新执行 = 整棵树搬到今天，已完成步骤保持完成） |
| 换外观 | 顶部「设置」或 `Cmd + ,`：深浅色 / 强调色 / 纸面色调 / 字号，附实时预览 |
| 备份 | 设置 → 导出备份（JSON）；从备份导入会整体替换并可撤销（导入前有确认） |

## 动效

全部短促、无弹跳，并尊重系统的「减少动态效果」（`accessibilityReduceMotion` 开启时一律取消）：

| 场景 | 效果 |
|---|---|
| 圆环打勾 / 撤销 | 填充 + 轻微放大回弹 |
| 任务增删、层级移动、角色变化 | 位置与透明度过渡（弹簧 0.34s） |
| 新建行 | 自上而下展开 + 淡入 |
| 悬停、按钮反馈 | 底色与透明度过渡（0.12s） |
| 拖拽落点 | 插入线与落点高亮淡入 |
| 切换日期 | 右栏整体淡入淡出 |
| 底部提示条 | 自下而上滑入 |

## 为什么分成四块

- **Core 不依赖 SwiftUI**：业务规则可以在没有图形环境的情况下自动验证。`SelfTest` 直接跑 Core，80 项断言覆盖日页取数、完成连带、撤销、忽略、恢复、重新执行连带上级与去重、清单三档范围、跨天不结转、拖拽四种情形、删除可撤销、持久化读写、外观设置持久化与备份导入导出。
- **UI 是独立库**：`YiRiYiJian`（应用）与 `RenderShots`（截图）共用同一套界面代码，所以评审看的就是真实界面，不是另画一版。
- **RenderShots 走 AppKit 渲染**（`NSHostingView` + `cacheDisplay`）：SwiftUI 的 `ImageRenderer` 不渲染 `ScrollView` 内容与文本框，会给出「空白列表」这种不可信的图。

## 界面表达层级的方式

一级 / 二级 / 三级同时用五条线索区分，避免只靠缩进：

日页里每个一级任务连同它的整棵子树是一张卡片（日页是纸色，卡片是纸上的白片）；卡片内部不画树线，层级靠缩进 + 角色图标 + 字号。一级卡片之间拖动 = 调整卡片顺序。

配色方案：**清爽（默认：浅灰底 + 纯白卡 + 品牌蓝，飞书那一路的克制现代感）** / 暖纸 / 墨蓝 / 炭墨 / 茶白。
默认字体是**苹果风**（系统无衬线 / 苹方）。冷色纸（浅蓝、墨蓝）配**冷调墨色**，暖色纸配暖调墨色——冷纸上写暖灰会发浑。

字号表：日期 19 / 分栏标题 15.5 / 主线 15.5 / 一级支线 14.5 / 二级 13 / 三级 12 / 次要信息 11 / 控件 12.5 / 输入 13。
分栏标题属于标题声部（纸墨风格下为宋体），与一级任务同档。

日历小格最多显示 4 条一级任务（超过 2 条时每条一行），放不下用「…」收尾；顺序与右栏一致（主线永远最前）。一级标题一律加粗。

「今日完成」一栏只列顶层完成树，一棵树 = 一张卡片；其中的子步骤不重复出现，栏内为空时整段隐藏。

日历里的时间方向：**今天**＝强调色，**过去**＝常规墨色，**还没到**＝整格浅灰（数字、文字、纸片一起压淡）。

角色小图标**只用在日历格子里**（标识主线/支线）；日页不画图标，靠栏位 + 缩进 + 字号。

| 线索 | 主线 | 支线 | 二级 | 三级 |
|---|---|---|---|---|
| 角色图标 | ◆ 菱形（强调色） | ● 实心圆 | □ 空心方 | ▪ 小方 |
| 字号字重 | 16.5 半粗 | 15 常规 | 13.5 常规 | 12.5 常规 |
| 字色 | 墨色 | 次墨色 | 次墨色 | 浅墨色 |
| 树线 | 无 | 无 | 1 级树线 | 2 级树线 |
| 缩进 | 0 | 0 | 22 | 44 |
| 完成圆环 | 18 | 18 | 15 | 13 |

顶层任务之间另有分隔线，用来回答「哪些子步骤属于哪件事」。
