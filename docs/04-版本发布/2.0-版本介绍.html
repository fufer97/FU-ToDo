01 / THEMES

四套浅色主题

每套主题有自己的底色、整页色块、字体与完成语言。默认是标本室；切换立即生效，不需要重启。

标本室 HERBARIUM默认

米纸、鼠尾草卡、窄黑体、标本标签与条码。完成时盖「DRIED & MOUNTED」日期章。

器物 ATELIER

奶油纸、赭红整页、宋体工单。每个一级任务是一张可交付的工单，完成时盖「已交付」圆章。

酸纸 ACID

荧光黄绿、重黑体、黑贴纸。最冲的一档，完成时贴一张「DONE」。

蓝图 BLUEPRINT

图纸底、蓝墨、标题栏与修订章。工具感最强的一档，完成时盖「REV. A」。

02 / CARD SPECIES

每套主题，有自己的卡片物种

不是一张卡片换四个颜色。工单关心工序，标本标签关心分类与位置，贴纸关心口号，图纸关心版本与比例——卡片上出现什么，由那个世界的专业习惯决定。

  • 器物工单 / 吊牌奶油纸、凸版双线、衬线编号；工单底部的日期与「待装订 / 已交付」。
  • 标本室标本标签窄黑体标题、ALT / LOC / ACC 规格行、真条码（用任务 ID 生成）。
  • 酸纸贴纸 / 告示黑贴纸、荧光字、硬投影与轻微旋转；PEEL HERE。
  • 蓝图图纸标题栏DWG NO / SCALE / DATE / REV 表格与「REV. A」修订章。
03 / LAYOUT

主界面重排

结构从「工具栏 + 两栏卡片」变成「报头 + 线格月历 + 满高日页」；颜色承担信息，卡片退成实物。

  1. 色块月历有主线的日子整格上色，支线用细线；今天是最深的一块。一眼看到这个月的节奏。
  2. 满高日页右侧是当天的一整页：104pt 日期、34pt 主线、等宽标签与页脚条码。
  3. 卡片即实物主线、支线、已完成都是当前主题的卡片；普通任务行保持安静，不跟卡片争。
04 / INTERACTIONS

交互也换了一套语言

完成不再只是打勾：每个主题盖自己的章；换日是一页翻过去；专注模式把整窗留给今天唯一的一件事。

  1. 完成盖章点圆环完成时，盖一枚当前主题的章：工单「已交付」、标本「DRIED & MOUNTED」、贴纸「DONE」、图纸「REV. A」。
  2. 翻页换日切换日期时右页横向翻入翻出，像翻过一页纸；系统开启「减少动态效果」时自动取消。
  3. 专注模式⌘⇧F 或顶栏「专注」：整窗只留今天的主线，点右侧大圆环完成，Esc 退出。
  4. 悬停展开月历格子悬停时多露出几条任务，不点开也能看个大概。
05 / SETTINGS

主题在设置里，一眼可换

设置页只留主题、字号、更新、引导与数据。旧的 5 套配色、深浅色与字体开关被移除；旧数据与旧备份会自动落到新主题，不丢内容。

  • 主题 四选一，带小预览与一句话说明；切换立即生效。
  • 字号 小 / 中 / 大三档，无障碍保留。
  • 迁移 旧设置文件里的 paper / accent / font 会被忽略，默认落到标本室。
  • 备份 仍是同一个 JSON；导入旧备份不会报错。
06 / UPDATE

怎么拿到 2.0

数据格式没有变，直接覆盖安装即可；首次打开会沿用你原来的任务与历史。

从源码构建

需要 macOS 14+ 与 Swift 6 工具链（命令行工具即可）。

cd app ./build.sh run # 编译 + 自测 + 启动 ./build.sh dmg # 生成安装包

直接安装

下载 GitHub Releases 里的 FU-ToDo-2.0.dmg，拖进「应用程序」，首次右键打开。
