02 / CARDS

每套主题，自己的卡片物种

不是一张卡片换三种颜色：工单、标本标签、图纸标题栏各自带着那个世界的字段与完成章。

  • 器物工单 / 吊牌奶油纸、凸版双线、衬线编号；页脚是「待装订 / 已交付」。
  • 标本室标本标签窄黑体标题、ALT / LOC / ACC 规格行、用任务 ID 生成的真条码。
  • 蓝图图纸标题栏DWG NO / DATE / REV 表格与「REV. A」修订章。
03 / LAYOUT

报头 + 线格月历 + 满高日页

颜色承担信息：今天浅灰、有内容的日子整格上色、已完成的日子变浅；卡片是页面上的实物。

  • 今天浅灰块 + 主题色描边不再用黑色块；靠近今天时一眼能找到。
  • 已完成更浅的主题色器物浅绿、标本室浅鼠尾草、蓝图浅蓝，退到背景里。
  • 计数未完成 7 / 已结束 3顶栏是带黑色计数徽章的按钮，点开各自清单。
04 / INTERACTIONS

交互也换了语言

完成盖章、翻页换日、悬停展开；这一版先下架了专注模式、⌘K 搜索和月度海报导出。

  • 盖章器物「已交付」/ 标本「DRIED & MOUNTED」/ 蓝图「REV. A」点圆环完成时先盖章，再让任务移走。
  • 翻页换日 = 翻页右页横向翻入翻出；系统开启「减少动态效果」时取消。

  • 设置三套主题 / 字号 / 音效旧数据自动落到标本室。

06 / UPDATE

怎么拿到 2.0.4

数据格式不变，直接覆盖安装；首次打开会沿用原来的任务与历史。

从源码构建

需要 macOS 14+ 与 Swift 6 工具链（命令行工具即可）。

cd app ./build.sh run # 编译 + 自测 + 启动 ./build.sh dmg # 生成安装包 ./tools/install.sh # 装进「应用程序」

直接安装

下载 GitHub Releases 里的 FU-ToDo-2.0.4.dmg，拖进「应用程序」，首次右键打开。
