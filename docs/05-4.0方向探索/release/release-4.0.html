〇二

主线只有一个标题槽

一天里最重要的那件事，用 DIN 窄体排成面板的标题——没有勾选框、没有子任务。完成走行尾按钮，触发一次全屏庆典礼成；完成后它留在原地，标着「今日主线已完成」，随时可以退回。

〇三

不惩罚没做完

昨天的任务不会自动涌进今天。未完成清单是一张未结委托登记纸：按日期分组，「N 天前」而不是「逾期」，没有红色警告。想把哪件搬回今天，点一下「重新执行」，整棵子树一起回来。
