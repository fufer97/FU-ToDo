〇一 · 为什么重做

我们把三套主题全删了

2.0 有三个「世界」：标本室、器物、蓝图。它们最终都成了贴纸——条码、修订章、LIVE 圆点，隐喻停在素材层，主线和支线长得一模一样。4.0 只留一页纸：层级交给字号，重点交给留白，红色只出现在今天。

〇二

主线即标题

一天里最重要的那件事，用 40pt 的衬线标题排进版心；支线是 15pt 的正文。字号即优先级——不用卡片、不用颜色，一眼知道今天该做什么。回车同级、Tab 下级，像大纲一样往下写。

〇三

不惩罚没做完

昨天的任务不会自动涌进今天。未完成清单是一张登记纸：「2 天前」而不是「逾期」，「已结束」而不是「已放弃」。想把哪件搬回今天，点一下「重新执行」，整棵子树一起回来。

〇四

月历只放密度

月历格子不再塞任务文字——中文从不被拦腰截断。有内容的日子只落一枚墨点，今天是唯一的朱砂圈，未来安安静静地淡着。整月一眼扫完，细节回到那一天。
